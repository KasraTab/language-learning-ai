# Language Learner App

An interactive language-learning application built with React and Vite.

The purpose of this project is to help users learn languages through vocabulary exercises, quizzes, pronunciation practice, progress tracking, and gamified learning experiences.

---

# Getting Started

## Install dependencies

```bash
npm install
```

## Start development server

```bash
npm run dev
```

## Build for production

```bash
npm run build
```

## Preview production build

```bash
npm run preview
```
